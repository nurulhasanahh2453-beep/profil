Ulangan Praktik: Pembuatan Web Berita Sederhana

Rancang dan ketik dokumen web tunggal bernama index.html

Tugas Anda adalah merancang halaman web portal berita sekolah yang bersih, terstruktur rapi, dan sesuai dengan sketsa tata letak (blueprint) di bawah. Halaman ini wajib memuat elemen pokok: Header, Sidebar Navigasi, Teks Berjalan, Gambar Utama, Deskripsi Artikel, Video Player, Tabel Agenda, dan Footer.

Sketsa & Tata Letak Halaman Web (Wireframe Blueprint)

Format Desain / Blueprint

Rincian Ketentuan Tag HTML yang Wajib Ada:

1 Struktur Dasar & Semantic

Wajib memuat hierarki standar HTML (<html>, <head>, <body>) serta tag semantik untuk Header dan Footer.

2 Navigasi Sidebar (<ul>, <li>, <a>)

Menggunakan tag list (<ul>, <li>) dan hyperlink (<a href="...">) untuk menu sidebar dan tautan footer.

3 Teks Berjalan (<marquee>)

Wajib memiliki tag <marquee> untuk animasi teks berita yang berjalan pada bagian atas konten.

4 Penyisipan Gambar (<img>)

Memiliki tag gambar (<img>) dengan atribut sumber berkas (src) untuk Gambar Utama.

5 Format Teks Deskripsi (P, B, I)

Menggunakan paragraf (<p>) yang di dalamnya memuat format teks tebal (<b>) dan miring (<i>).

6 Penyematan Video (<video>)

Menyisipkan video lokal dengan kontrol pemutar menggunakan tag <video controls>.

7 Tabel Data (Rowspan/Colspan)

Tabel (<table>, <tr>, <td>) wajib menerapkan penggabungan sel baris atau kolom (rowspan / colspan).

8 Atribut HTML Lengkap

Memanfaatkan atribut seperti width, height, dan border dengan tepat untuk mengatur dimensi elemen dan garis tepi tabel.
